[Разбор](../README.ru.md) · [Источники](evidence.md)

## Попытки, которые нельзя превращать в рецепт

- Повторные полные прошивки не исправили обнаруженную остановку DRAM.
- Ранние LK-эксперименты не были причиной первого успешного старта Android: до него их сняли. Поздний GSI-переход использовал отдельно проверенную LK-делегацию.
- Принудительное включение второго ранга провалило memory test.
- Публичные тестовые ключи не совпали с OEM-ключами; «переподписали родной подписью» — неверное описание.
- Одна успешная компиляция SELinux не обнаружила несовместимые property contexts.
- Обычные GMS APK и отдельная выдача development-permission не дали полноценную Google-интеграцию.
- Глобальный permissive не использовался как окончательное исправление политики.
- Отключение restore helper ухудшило работу GMS и было отменено.
- Нулевой `input tap` не проходил один экран TikTok; короткое стационарное нажатие 160 мс сработало. Это частный UI-результат, не универсальный обход согласий.
- Старое координатное нажатие однажды открыло другой экран Settings. Настройки там не меняли; далее добавили проверку свежего UI и текущего пакета перед нажатием.
- `cmd overlay fabricate` с integer-типом не создавал нужный dimension; использовали float API с явной единицей PX.
- Fabricated overlays и `debug.renderengine.backend` не пережили полный reboot в этой конфигурации; runtime-помощник повторно проверяет и применяет их при запуске.

Новые результаты другой модели, памяти или сборки следует добавлять как отдельное наблюдение с собственными условиями и доказательствами.
